FESAutenticadorServiceServiceSoapBinding

SOAP Version: 1.1

Main class which you can use to connect to your web service

Important settings

  • Timeout - the timeout for network operations, in milliseconds. By default: 60 sec.
    Example:
                        
FESAutenticadorServiceServiceSoapBinding service = new FESAutenticadorServiceServiceSoapBinding(null,"http://192.168.1.103:8080/exitus-webservice/services/AutenticadorServicePort",30000);
service.getIdentificadorUsuario();
  • Url - the web service address. By default it is retrieved from the wsdl file
    Example:
                        
FESAutenticadorServiceServiceSoapBinding service = new FESAutenticadorServiceServiceSoapBinding(null,"http://192.168.1.103:8080/exitus-webservice/services/AutenticadorServicePort");
service.getIdentificadorUsuario();
  • httpHeaders - allows you to add custom headers to the http requests.
    Example:
                        
FESAutenticadorServiceServiceSoapBinding service = new FESAutenticadorServiceServiceSoapBinding();
service.httpHeaders.add( new HeaderProperty("Authorization","Basic QWxhZGRpbjpPcGVuU2VzYW1l"));
service.getIdentificadorUsuario();
  • Enable logging - if you enable logging, all requests/responses will be write to the console (for debugging purposes)
    Example:
                        
FESAutenticadorServiceServiceSoapBinding service = new FESAutenticadorServiceServiceSoapBinding();
service.enableLogging=true;
service.getIdentificadorUsuario();
